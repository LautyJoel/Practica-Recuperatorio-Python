## Instalación

- Abrir Powershell/Bash/CMD/Terminal y navegar a la carpeta del proyecto.
- Correr `py -m venv .venv` para crear el entorno virtual venv donde se instalarán las dependencias.
- Activar el entorno virtual con `.venv/Scripts/activate` o `source .venv/Scripts/activate` según el sistema operativo.
- Correr `pip install -r requirements.txt` para instalar las librerías desde el archivo de requierements.txt.
- Correr `fastapi run` para iniciar el servidor de la aplicación en localhost sobre el puerto por defecto (8000).
- Abrir el navegador e introducir la dirección [localhost:8000/docs](localhost:8000/docs) para ver la documentación swagger de la aplicación.
